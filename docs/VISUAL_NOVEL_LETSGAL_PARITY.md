# LetsGal Studio comparison and Pocket VN acceptance gaps

See the [Goal acceptance criteria](VISUAL_NOVEL_GOAL.md) for the current objective and quantitative gates. The 54 groups and their subitems remain the full feature scope.

Comparison date: 2026-11-07. The baseline is the official v2.5.0 manual. Promotional videos and third-party reverse engineering do not establish feature coverage. See the [complete index](https://docs.avg-engine.com/llms.txt), [current version features](https://docs.avg-engine.com/updates/2-5-0), and [runtime and editor overview](https://docs.avg-engine.com/manual/start/what-is). This is a living acceptance checklist. Source code and underlying Pocket components alone cannot establish a complete VN feature.

The user asked for the strengths of engines on the market to be covered and editable in the Editor. All listed gaps remain in scope. Acceptance requires actual editing, saving, compilation, execution, and player input. External services and platform features require working integrations verified in the target environment.

Domain references include [story instructions](https://docs.avg-engine.com/manual/writing/blocks-overview), [visual UI](https://docs.avg-engine.com/advanced/visual-ui-editor), [animated models](https://docs.avg-engine.com/manual/creating/dynamic-visuals), [voice and glyph audio](https://docs.avg-engine.com/manual/writing/voice-management), [localization](https://docs.avg-engine.com/manual/writing/localization), [collaboration](https://docs.avg-engine.com/manual/overview/collaboration), and [build and distribution](https://docs.avg-engine.com/manual/overview/build). The official glyph audio feature plays synthesized short sounds alongside text. TTS is a separate feature that produces intelligible speech.

## Redundancies removed through ablation

- The Editor and game share `story.json`. `story.ts` is only the typed export.
- Art and audio share `novel.assets.json`. The build wrapper passes registered image paths to the existing resource collector, creating one PAK and surfacing missing images as errors.
- Rollback uses one bounded sequence. Checkpoints retain a cursor and avoid serializing the entire backlog each time.
- The audio adapter calls native only when intent changes. Frame snapshots leave the playing BGM undisturbed.
- The clock uses Pocket virtual deadlines and stays idle after manual reading completes.
- The engine snapshot holds one player input draft and reuses native InputField and HostBridge. Real input testing prompted removal of a local FocusScope that blocked the journal. Saves and rollback need no additional controller.

Continue validating these simplifications as features expand and preserve the required capability scope.

See [per-line voice](VISUAL_NOVEL_VOICE.md), [localization](VISUAL_NOVEL_LOCALIZATION.md), and the [Editor](VISUAL_NOVEL_EDITOR.md) for acceptance on 2026-11-07. The remaining market capability gaps stay in scope.
